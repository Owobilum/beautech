# @owobilum design system

Accessible React components built on [Headless UI](https://headlessui.com) and
styled with Tailwind CSS v4, with design tokens implemented from Figma.

| Package            | Contents                                        |
| ------------------ | ----------------------------------------------- |
| `@owobilum/ui`     | React components                                |
| `@owobilum/styles` | Design tokens and the Tailwind theme (CSS only) |

## Getting started

The packages are published to [GitHub Packages](https://github.com/Owobilum/beautech/packages),
which requires authentication to install. Add an `.npmrc` to your app:

```ini
@owobilum:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

`GITHUB_TOKEN` must be a GitHub token with the `read:packages` scope (a
personal access token locally; in another repo's GitHub Actions, grant that
repo access in the package settings and use the workflow's `GITHUB_TOKEN`).

```bash
npm install @owobilum/ui react react-dom tailwindcss
```

Import Tailwind and the library styles in your app's main stylesheet. This
brings in the design tokens, the semantic utilities (`bg-primary`,
`text-primary-foreground`, …) and tells Tailwind to generate the classes the
components use.

```css
@import 'tailwindcss';
@import '@owobilum/ui/styles.css';
```

The font stack expects [Inter](https://rsms.me/inter/); load it in your app.

```tsx
import { Button } from '@owobilum/ui';

export function SaveButton() {
  return <Button onClick={save}>Save</Button>;
}
```

## Accessibility

Every story is run as a test in a real browser with
[axe](https://github.com/dequelabs/axe-core) accessibility checks, and
interactive stories include keyboard interaction tests. See the
**Accessibility** and **Interactions** panels on each story.

Every story is also a visual regression test: [Chromatic](https://www.chromatic.com)
snapshots each one and flags pixel changes for review on pull requests.
