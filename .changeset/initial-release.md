Initial release.

- `@owobilum/styles`: semantic design tokens (colors, focus rings, Inter font stack) as CSS variables, exposed as Tailwind CSS v4 utilities via `@theme inline`.
- `@owobilum/ui`: accessible `Button` built on Headless UI, with `primary`, `secondary`, `danger`, `danger-outline` and `ghost` variants, four sizes, leading/trailing icons and a focusable loading state. Import `@owobilum/ui/styles.css` after `tailwindcss` to set up tokens and styles.
